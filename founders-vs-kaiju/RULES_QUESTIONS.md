# Rules Questions

The v0.2 tabletop rules currently have **no unresolved structural rules gaps**.

Use this file only when implementation reveals wording that genuinely cannot be resolved from the working rules document.

Do not use this file to propose new mechanics.

## Open — non-structural timing / chooser wording

### Q1 — River Crossing extra Fortification loss

D03 currently says:

> Wave Breach also discards 1 Fortification.

The rules do not explicitly say who chooses that Fortification after the normal Breach capacity reduction.

**HTML v0.2 convention:** Washington chooses the additional Fortification to discard.

K14 Deep Current still controls only the Fortification lost specifically to the Breach capacity reduction, as written.

This does not change the game's structure, but should be confirmed before final card wording.

### Q2 — Multiple Wave-prevention Fortifications

If W10 Emergency Repairs and W18 John Paul Jones are both installed where the same Wave enters, both prevention triggers can become eligible from the same Wave movement.

**HTML v0.2 convention:** Washington chooses their resolution order.

- If W18 resolves first, the Wave is destroyed and later prevention effects that require that Wave are skipped.
- If W10 resolves first, it prevents the pending impact; W18 may then resolve and destroy the still-present Wave.

This should be confirmed as the tabletop simultaneous-trigger convention before final rules lock.
